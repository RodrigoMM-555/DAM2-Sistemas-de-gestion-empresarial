# Proyecto

El proyecto será una aplicación de gestión para grupos scouts que permitirá centralizar la información de usuarios, familias, educandos, avisos, circulares, documentos y asistencias.

He planteado desarrollar una aplicación propia en lugar de adaptar un ERP o CRM genérico porque algunas necesidades de los grupos scouts son específicas y así podremos ajustar mejor sus funcionalidades. Además, considero que existe una oportunidad para ofrecer soluciones digitales a un ámbito que todavía tiene margen de mejora en este aspecto.

Quiero mantener PHP, MySQL, HTML, CSS y JavaScript para aprovechar los conocimientos adquiridos y utilizar tecnologías adecuadas al proyecto. La aplicación tendrá una arquitectura por capas y una API que intercambiará datos en formato JSON. Esto facilitará el mantenimiento y permitirá reutilizar el servidor si en el futuro desarrollamos una aplicación móvil.

Para el desarrollo utilizamos Ubuntu y mantendremos MySQL como base de datos relacional. Para gestionar archivos como PDF e imágenes, valoraremos almacenarlos por separado y guardar en la base de datos sus rutas y la información necesaria para administrarlos. Antes del despliegue comprobaremos la compatibilidad de las versiones y la configuración del servidor.

Como se gestionarán datos personales de familias y menores, será importante controlar los permisos, proteger los documentos y aplicar medidas adecuadas de seguridad y protección de datos. También revisaremos las licencias de las herramientas y dependencias utilizadas.

Estas decisiones buscan que WebScout sea una aplicación especializada, mantenible y preparada para evolucionar.
