# Resultado de aprendizaje: Identificación de sistemas ERP-CRM

**a) Sistemas ERP-CRM:** He aprendido a reconocer soluciones ERP y CRM y
sus funciones. Esto me ha ayudado a valorar qué tipo de sistema se
adapta mejor a WebScout 2.0.

**b) Tipos de licencia:** He aprendido a distinguir entre software de
código abierto y propietario, y a tener en cuenta sus condiciones de uso
y posibles costes al elegir tecnologías.

**c) Comparación de sistemas:** He comprendido que hay que comparar
funcionalidades, requisitos y costes. Para WebScout 2.0 planteamos una
aplicación propia porque sus necesidades son específicas de los grupos
scouts.

**d) Sistema operativo:** He aprendido a comprobar la compatibilidad de
cada sistema con los sistemas operativos. Para desarrollar WebScout
utilizo Ubuntu, aunque el entorno de producción se decidirá según el
alojamiento.

**e) Gestor de datos:** He aprendido a valorar los gestores de bases de
datos según los requisitos del sistema. En WebScout planteamos mantener
MySQL para relacionar usuarios, educandos, avisos y asistencias.

**f) Configuración:** He comprendido la importancia de comprobar que el
sistema operativo, PHP, el servidor web y MySQL estén correctamente
configurados y sean compatibles.

**g) Documentación:** He aprendido a documentar las tecnologías
elegidas, las decisiones y los procedimientos para facilitar el
mantenimiento del proyecto.

**h) Incidencias:** He aprendido que se deben registrar los problemas
que surjan, las comprobaciones realizadas y las soluciones aplicadas,
sin incluir incidencias que no hayan ocurrido.
